# Private Cloud Infrastructure

Self-hosted personal cloud.

## Services

- Immich - Photos and Videos
- Nextcloud - Files, Contacts, Calendar
- Vaultwarden - Password Management
- SMB - Network Storage
- Tailscale - Private Network Access

## Infrastructure

- Docker
- Docker Compose
- WSL2
- Windows 11
- Future Linux NAS

## Goals

- Data ownership
- No dependency on commercial cloud storage
- Portable infrastructure
- Automated backups
- Easy migration
